# Post LinkedIn — lancement vidéo Inko

## Post (à coller tel quel, vidéo Inko-LinkedIn.mp4 en pièce jointe)

J'ai construit l'app de lecture que je voulais utiliser. 📚

Mangas, light novels, livres… tout était éparpillé entre des sites, des comptes et des pubs.
Alors j'ai créé Inko.

→ Une seule bibliothèque pour tout ce que tu lis
→ Un lecteur manga (page, double, webtoon) et un lecteur de romans
→ Tu reprends exactement là où tu t'es arrêté
→ Alertes de nouveaux chapitres, synchro AniList, import EPUB / CBZ / PDF
→ Sur Windows, Android et le web : le PC sert de hub au téléphone

Et surtout : sans compte, sans pub, sans pistage.
Ta bibliothèque, ta progression et tes notes restent chez toi.

Côté technique, c'est un projet full-stack que j'ai mené de bout en bout :
• Front en JavaScript vanilla, sans framework, installable en PWA
• Back Node.js / Express / MySQL
• App Windows avec Tauri 2, app Android avec Capacitor
• Un système d'extensions ouvert (MangaDex, Project Gutenberg…)
• Tests unitaires et E2E (Playwright), CI GitHub Actions

Le projet est gratuit et open source (Apache 2.0).
